02 GPIO Control & P17 Expansion Header

Linux calculates sysfs GPIO numbers on i.MX6ULL via: GPIO Number = (Bank - 1) × 32 + Pin.

  • GPIO1 = gpiochip0 (Pins 0–31) • GPIO2 = gpiochip1 (Pins 32–63) • GPIO3 = gpiochip2 (Pins 64–95)
  • GPIO4 = gpiochip3 (Pins 96–127) • GPIO5 = gpiochip4 (Pins 128–159)
P17 Pin SoC Pad Linux Sysfs GPIO gpiod Line Default Mode Notes & Safety
Pin 8 CSI_HSYNC GPIO 116 (GPIO4_IO20) gpiochip3 Line 20 User GPIO / I2C2 SCL Primary user GPIO pin. Fully safe for arbitrary digital I/O.
Pin 9 CSI_MCLK GPIO 113 (GPIO4_IO17) gpiochip3 Line 17 User GPIO / I2C1 SDA Shared with Touchscreen and RTC on I2C1 bus.
Backlight GPIO1_IO08 GPIO 8 (GPIO1_IO08) gpiochip0 Line 8 PWM / Backlight LCD backlight brightness & display sleep control.
UART3 TX UART3_TX GPIO 24 (GPIO1_IO24) gpiochip0 Line 24 UART3 Transmit Repurposable if UART3 peripheral is unused.
UART3 RX UART3_RX GPIO 25 (GPIO1_IO25) gpiochip0 Line 25 UART3 Receive Repurposable if UART3 peripheral is unused.

Controlling GPIO Lines (Command Line)

# Method 1: Using modern libgpiod tools (Recommended)
gpioset gpiochip3 20=1     # Drive Pin 8 (chip 3 line 20) HIGH
gpioset gpiochip3 20=0     # Drive Pin 8 LOW
gpioget gpiochip3 20       # Read current logic state (returns 0 or 1)

# Method 2: Using legacy sysfs interface (/sys/class/gpio)
echo 116 > /sys/class/gpio/export
echo out > /sys/class/gpio/gpio116/direction
echo 1   > /sys/class/gpio/gpio116/value
cat /sys/class/gpio/gpio116/value
echo 116 > /sys/class/gpio/unexport

Testing & Communicating via UART:

# Configure baud rate and raw transmission mode
stty -F /dev/ttymxc1 115200 raw -echo

# Transmit data frame
echo "TEST_DATA_FRAME" > /dev/ttymxc1

# Read incoming stream
cat /dev/ttymxc1

spidev_test -D /dev/spidev0.0 -s 1000000 -v

06 Remote OTA Update Agent Service

The ota-agent.service daemon runs in the background, polling an HTTP server for firmware update packages (update.swu) and writing them into the alternate rootfs bank (Dual A/B Bank fail-safe architecture with automated rollback).

Setting Configuration File Default Value Description
OTA_SERVER_URL /etc/ota-server.conf http://192.168.1.100:8000 Base HTTP endpoint hosting version.json & update.swu
CHECK_INTERVAL /etc/ota-server.conf 30 Background check frequency in seconds 
# Modify server URL or interval, restart service, and inspect live activity:
vi /etc/ota-server.conf
systemctl restart ota-agent
journalctl -u ota-agent -f

07 Display Sleep & Touch-to-Wake Service

The hmi-sleep.service daemon monitors /dev/input/touchscreen0. When no touch events occur for the configured inactivity period, it blanks the LCD framebuffer and turns off the backlight power. Touching anywhere on the screen immediately wakes the display.

Setting Configuration File Default Supported Values
SLEEP_TIMEOUT_SEC /etc/hmi-sleep.conf 120 (2 min) 0 = Always ON (Sleep disabled) • 30 = 30s • 300 = 5 min 
# Change sleep timeout and apply immediately:
sed -i 's/^SLEEP_TIMEOUT_SEC=.*/SLEEP_TIMEOUT_SEC=300/' /etc/hmi-sleep.conf
systemctl restart hmi-sleep

08 USB Flash Drive Auto-Update Workflow

The board's launcher service (qt-auto-launcher.service) automatically checks attached USB flash drives on boot or restart, updates the application binary at /opt/hmi/bin/app, and executes it immediately.

Format Compatibility: Format the USB flash drive as FAT32. The launcher automatically mounts and handles both partitioned drives (sda1) and whole-disk drives (sda).

Step 1: Prepare the USB Flash Drive on Any PC

Copy these two files directly into the root directory of the FAT32 USB drive:

Filename Type File Content / Purpose
UpdateCont Text File Contains single character: Y (authorizes auto-update)
test or app ARM 32-bit Executable New compiled Qt ARM application binary to install

Step 2: Trigger Update on the Board

  • Method A (Power-On / Reboot): Insert the USB drive and reboot the board. The update applies automatically on boot.
  • Method B (Live Update without Reboot): Insert the USB drive and run via console: 
    systemctl restart qt-auto-launcher

Step 3: Verification

# 1. View launcher update log
journalctl -u qt-auto-launcher -n 25 --no-pager

# 2. Confirm binary size and timestamp
ls -l /opt/hmi/bin/app
